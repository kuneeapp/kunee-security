# KUNEE Security

This folder is a **documentation-only sample** for security reporting and careful review of project materials. It is a practical starting point for communicating concerns safely; it is not an audit, certification, vulnerability assessment, or statement that any system is free of vulnerabilities.

## Contents

- [Review checklist](./REVIEW-CHECKLIST.md) — non-sensitive prompts for reviewing documentation and example changes.
- [Security reporting policy](./SECURITY.md) — how to report concerns privately and safely.
- [Contributing](./CONTRIBUTING.md) — contribution boundaries for this material.
- [Changelog](./CHANGELOG.md) — planned documentation updates.

## Status and reporting

The `0.1.0-preview` documentation-only prerelease is planned; it does not indicate a security review or product release. Use the checklist as a prompt, not as a certification or proof of safety.

Send suspected vulnerabilities or accidental sensitive-data exposure privately to [support@kunee.app](mailto:support@kunee.app). Share a concise description, affected component or document, and safe reproduction steps. Do not include passwords, private keys, recovery phrases, or personal data. Please avoid public disclosure while an issue is unresolved; do not probe systems without authorization. No response deadline or bounty is promised here.

Any contract activity mentioned by project materials is **operator-only testing**, not an approval for public use. For contract information, consult only the [deployment record](https://github.com/kuneeapp/kunee-contracts/blob/main/DEPLOYMENTS.md).
