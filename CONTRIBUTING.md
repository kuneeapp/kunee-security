# Contributing security guidance

Help keep this security material precise, useful, and safe. This is a documentation-only sample, not a vulnerability database or a record of completed security reviews.

## Contribution principles

- Use clear, measured language. Do not claim an audit, certification, fix, or security guarantee without verifiable authorization.
- Keep sensitive reports private; do not add exploit details that would enable unauthorized access.
- Do not commit secrets, private key material, recovery phrases, personal data, or identifying logs.
- Distinguish operator-only tests from public release or public-funds approval.
- Refer to contract information only through the [deployment record](https://github.com/kuneeapp/kunee-contracts/blob/main/DEPLOYMENTS.md).

In a proposed edit, explain what factual ambiguity it resolves and avoid presenting assumptions as established facts. Contact [support@kunee.app](mailto:support@kunee.app) for questions.
