# Security reporting policy

This repository contains sample-only security guidance. It does not represent an audit, guarantee, or assurance about the security of KUNEE products or infrastructure.

## Private reporting

Email suspected vulnerabilities or accidental exposure to [support@kunee.app](mailto:support@kunee.app). Provide the affected area and safe reproduction details. Do not attach credentials, private keys, recovery phrases, real user data, or other secrets.

Please allow the issue to be assessed before public disclosure. Do not access, alter, or disrupt systems without explicit authorization. This policy does not guarantee a response time, reward, or remediation outcome.

## Scope and status

This documentation-only sample is not an authorization to test any service. Any contract activity described by project materials is operator-only testing, not a public-use release. Contract information is available only through the [deployment record](https://github.com/kuneeapp/kunee-contracts/blob/main/DEPLOYMENTS.md).
